# 招新内容的初始数据

本目录**只在服务器第一次启动时使用一次**：如果 `data/recruit-content/` 还不存在，系统会把这里的内容复制过去（本说明文件除外）。之后所有招新内容都以 `data/recruit-content/` 为准，在管理后台的“招新”标签页里编辑，不再读取本目录，修改本目录也不会同步到已运行的网站。

当前的初始数据只有批次清单 `cohorts.json`，三个批次都是“未发布”，所以代码部署后访客什么也看不到，直到管理员在后台写好内容并发布。

## 日常怎么用

在管理后台打开“招新”标签页：

- **发布**：写好之后点“立即发布”，或设置一个北京时间让系统到点自动发布。发布会把这一期设为“本次招新”，原来的“本次招新”转为“往期”，并可以同时发布所有草稿文档。
- **文档**：所见即所得地编辑，不需要懂 Markdown。输入 `/` 选择标题、列表、待办、引用、代码块、表格、图片；选中文字会出现加粗、斜体、链接等工具栏；**直接粘贴截图或把图片拖进来**，图片会自动上传并显示。**从网页、飞书等复制整篇内容再粘贴进来也可以**：标题、列表、表格、代码块（连同语言）、加粗、链接都会保留，粘贴后图片会自动下载并转存到本站，不再依赖原来的网站。也可以切换到“Markdown 源码”，或导入 `.md` 文件。勾选“草稿”的文档访客看不到。
- **图片与附件**：上传图片、PDF、Word、PPT 等，在文档里用相对路径引用。引用文档类文件会在页面底部自动生成“附件下载”列表。
- **批次设置**：批次名称、状态、选择方向（本次是十篇论文）、提交截止时间、是否开放提交。

## 文档写法

文件头信息（后台已经用表单替你填好）：

```markdown
---
title: GPT-2 教程
order: 2
summary: 一句话简介
draft: false
---

# 正文从这里开始
```

- 支持标题、列表、任务列表、表格、代码块（带语言名会高亮）、引用、图片（可加图注）、链接；原始 HTML 会被丢弃，不会显示。
- 文档之间互相链接，直接写文件名：`[BERT 教程](bert.md)`。
- 图片和附件用相对路径引用：`![整体结构](assets/gpt2.png)`、`[报告模板](templates/report.docx)`。
- 文档名 `index` 是总招新文档，始终排第一；`submit` 和 `submissions` 被系统占用。

## 数据与备份

内容、附件和收到的提交都在服务器的 `data/` 目录里（`recruit-content/` 和 `recruit-submissions/`），Docker 部署时它是持久化的数据卷。**重新部署不会覆盖它们，但请把整个 `data/` 目录纳入备份。**
